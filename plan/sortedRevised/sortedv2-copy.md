# Sorted Website Copy Brief v2.0

## Purpose

This is **not** a lead generation landing page.

It is a **credibility website**.

Visitors arrive here after:

* receiving an email
* watching a review
* clicking from LinkedIn
* seeing content
* hearing about Sorted

They are validating one thing:

> **Do these people actually understand businesses like mine?**

The site should answer **yes** within the first few seconds.

# Voice & Tone

Simple.

Confident.

Human.

Never clever.

Never technical.

Never salesy.

Every sentence should feel obvious.

The goal is not to impress.

The goal is to make the visitor think:

> "Yeah."

Avoid:

* AI jargon
* automation jargon
* workflow jargon
* operational jargon
* efficiency jargon

Instead use language local business owners already use.

Examples:

✓ wasting time

✓ chasing customers

✓ repeating yourself

✓ missed calls

✓ following people up

✓ copying information

✓ replying to the same questions

Every section should feel like we're describing the visitor's own business.

# Design Principles

Maintain the existing Sorted design language:

* Generous whitespace
* Large bold typography
* Minimal colour palette
* Editorial feel
* Black and white foundation
* Bright accent colour used sparingly for emphasis
* Playful without feeling childish
* Clean enough to feel premium

Avoid making the experience feel like software.

Avoid generic SaaS layouts.

Avoid dashboards dominating every section.

The website should still feel like a modern brand first.

---

# Copy Principles

Every sentence must satisfy at least one of these:

* Recognition ("That's us.")
* Relief ("Finally.")
* Simplicity ("That makes sense.")
* Confidence ("They've done this before.")

If a sentence explains technology instead of describing a business problem, remove it.

If a sentence sounds like a consultant, simplify it.

If a sentence sounds like an engineer, rewrite it.

If a sentence makes the visitor nod, keep it.

---

# The One Rule

Every visitor should leave with exactly one thought:

> **"These people understand the annoying parts of running a business."**

If the site achieves that, everything else becomes easier. It aligns perfectly with your outreach-first acquisition model and with the original Sorted doctrine of reducing friction and earning trust through demonstration rather than persuasion.
