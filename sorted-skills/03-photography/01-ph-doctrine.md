# Photography Doctrine

## Purpose

Photography is the primary trust signal within the Sorted Design Language.

Visitors judge photography before they judge typography.

Photography therefore carries the greatest responsibility for communicating professionalism.

Every image should function as evidence.

Not decoration.

---

# Core Philosophy

Photography should answer:

"What visual proof does the visitor need before they trust this business?"

Never ask:

"What image would look nice here?"

---

# The Hierarchy of Photography

Evidence

↓

Experience

↓

Environment

↓

Product

↓

Decoration

Always prefer evidence over decoration.

---

# Rule 01

People trust people.

Whenever appropriate:

Show humans before products.

Show interaction before objects.

Show relationships before features.

---

# Rule 02

Real environments.

Real work.

Real situations.

Avoid staged perfection.

Authenticity creates confidence.

---

# Rule 03

Every image should communicate one idea.

Examples:

Competence

Luxury

Care

Precision

Warmth

Community

Transformation

Never attempt to communicate everything.

---

# Rule 04

Images should increase confidence.

Ask:

What uncertainty does this photograph remove?

---

# Rule 05

Avoid decorative stock imagery.

Every image should have commercial purpose.

If removing the image changes nothing,

the image should not exist.

---

# Rule 06

Consistency

Photography should appear to come from one photoshoot.

Lighting.

Colour grading.

Lens choice.

Perspective.

Wardrobe.

Emotion.

Should feel consistent.

---

# Narrative Sequencing

Photography should function as a visual story, not as isolated illustrations.

For a service business, the preferred narrative sequence across the page is:

```
Arrival
↓
Diagnosis
↓
Repair
↓
Result
↓
Satisfied Customer
↓
CTA
```

Each image should feel like the next moment in a continuous customer journey.

- Hero: the problem and the promise (Arrival / Diagnosis)
- Services: the work being done (Diagnosis / Repair)
- Process: the method and care (Repair)
- About: the result and the people behind it (Result)
- Testimonials: the satisfied customer (Satisfied Customer)
- CTA: the invitation to begin (Arrival)

Never repeat the same visual moment in two sections.

# Validation

Every image should answer:

Why is this image here?

What trust does it create?

What moment in the customer journey does it represent?

If none of these answers exist,

replace the image.
