# Micro Interactions

## Purpose

Micro interactions provide confidence.

Every interaction should acknowledge user intent.

---

# Examples

Buttons.

Navigation.

Cards.

Forms.

Tabs.

Inputs.

---

# Behaviour

Hover.

↓

Slight elevation.

Click.

↓

Compression.

Release.

↓

Return.

Focus.

↓

Clear outline.

Never rely on colour alone.

---

# Rules

Immediate feedback.

Minimal movement.

Consistent timing.

Consistent easing.

---

# Validation

Every interaction should reassure.

Never entertain.
