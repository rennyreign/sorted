# Scroll Behaviour

## Purpose

Scrolling is narrative.

The page should reveal itself naturally.

Never dump information.

---

# Reveal Order

Photography.

↓

Headline.

↓

Supporting copy.

↓

CTA.

---

# Rules

Sections should arrive progressively.

Large content should never appear simultaneously.

Animation should support reading order.

---

# Avoid

Parallax abuse.

Infinite motion.

Competing animations.

Delayed usability.

---

# Validation

Scrolling should feel calm.

Not theatrical.
