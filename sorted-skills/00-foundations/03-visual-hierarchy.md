# Visual Hierarchy

## Purpose

Visual hierarchy determines how attention moves through a webpage.

It exists before typography.

Before colour.

Before components.

Hierarchy is the order in which the human eye receives information.

A website should never force the visitor to decide where to look first.

The hierarchy should make that decision automatically.

---

# Core Principle

Attention should always flow.

Never compete.

Every viewport should have one obvious focal point.

Everything else exists to support that focal point.

---

# Rule 01

## One Primary Element

Every viewport should contain one dominant element.

Examples:

- Headline
- Photography
- Product
- CTA

Never create multiple competing primary elements.

---

# Rule 02

## The Reading Path

The natural reading order should become:

Primary

↓

Supporting

↓

Evidence

↓

Action

↓

Continuation

If the eye jumps randomly, hierarchy has failed.

---

# Rule 03

## Scale Creates Importance

Importance is communicated through scale.

Use:

- typography
- spacing
- image size
- whitespace
- contrast

before colour.

Do not increase visual noise.

Increase emphasis.

---

# Rule 04

## Proximity Creates Relationships

Elements positioned together should belong together.

Whitespace communicates separation.

Never rely on borders to create grouping.

Use spacing first.

---

# Rule 05

## Contrast Creates Focus

Contrast exists in many forms.

Light vs dark.

Large vs small.

Dense vs sparse.

Sharp vs soft.

Use contrast intentionally.

Never decorate with contrast.

---

# Rule 06

## Every Section Has One Purpose

Sections should answer one question only.

Examples:

Hero

↓

What is this business?

Services

↓

What do they do?

Testimonials

↓

Can they be trusted?

CTA

↓

What happens next?

Never mix purposes.

---

# Rule 07

## Breathing Space

High trust websites breathe.

Allow space around important decisions.

Crowded interfaces reduce confidence.

---

# Rule 08

## Progressive Density

Early sections should be visually simple.

Later sections may become denser.

Never overwhelm the first viewport.

Confidence precedes information.

---

# Validation

Every viewport should answer:

Where do I look?

What is important?

What should I do next?

If any answer is unclear,

the hierarchy is incorrect.
