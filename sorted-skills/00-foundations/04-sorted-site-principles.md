# Sorted Site Principles

## Purpose

These principles define what makes a website feel like a Sorted website.

This is not a visual style.

It is an engineering philosophy.

Every industry should express these principles differently.

The principles themselves never change.

---

# Principle 01

Trust before explanation.

The website should feel trustworthy before attempting to educate.

---

# Principle 02

Clarity over creativity.

Creative decisions should improve clarity.

Never reduce clarity for originality.

---

# Principle 03

Whitespace is functional.

Whitespace exists to improve comprehension.

Never fill empty space.

---

# Principle 04

Photography proves.

Copy explains.

Always prefer showing over telling.

---

# Principle 05

Modernity creates confidence.

Visitors associate modern interfaces with competent businesses.

Outdated interfaces reduce perceived capability.

---

# Principle 06

Everything earns its place.

Every element must increase one of:

Trust

Understanding

Action

If it does not,

remove it.

---

# Principle 07

Interfaces disappear.

The customer should notice the business.

Not the website.

---

# Principle 08

Consistency beats decoration.

Professionalism comes from rhythm.

Not embellishment.

---

# Principle 09

Less but better.

Every reduction in complexity should increase confidence.

---

# Principle 10

The website is not the product.

The website is the trust engine.

Trust produces enquiries.

Enquiries produce customers.

Every design decision should ultimately support this sequence.
