# Editorial Visual Language

## Purpose

Editorial is the highest-trust visual language within the Sorted Design Language.

It communicates confidence through restraint rather than decoration.

Editorial layouts resemble premium magazines rather than software products.

This language should be selected when trust is built through expertise, quality or aspiration.

Examples:

Luxury trades

High-end fitness

Architecture

Interior design

Beauty clinics

Professional coaching

Private healthcare

---

# Core Philosophy

Editorial design creates confidence by reducing visual noise.

Every element should feel intentional.

The design should never appear busy.

Visitors should feel calm rather than impressed.

---

# Characteristics

Large typography.

Generous whitespace.

One dominant image.

Minimal interface chrome.

Few borders.

Subtle colour palette.

Long visual rhythm.

Controlled density.

---

# Typography

Typography carries much of the hierarchy.

Headlines should feel oversized.

Body copy should remain restrained.

Avoid excessive font weights.

Avoid unnecessary uppercase.

---

# Photography

Photography should dominate.

Images should feel:

expensive

architectural

real

purposeful

Images should occupy space confidently.

Never reduce photography to decoration.

---

# Colour

Restrained.

Neutral.

Limited palette.

Accent colours should exist only to reinforce interaction.

Never decorate with colour.

---

# Components

Preferred:

Large Hero

Split Hero

Editorial Grid

Case Studies

Large Testimonial

Image Sections

Timeline

Process

Avoid:

Feature card overload

Icon grids

Small cards

Dense dashboard layouts

Heavy borders

---

# Motion

Motion should be slow.

Confident.

Subtle.

Fade.

Translate.

Scale.

Never bounce.

Never overshoot.

Never distract.

---

# Validation

Does this feel premium because of restraint?

Or because of decoration?

If decoration,

simplify.
