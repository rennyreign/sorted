# Build First, Charge Second

Sorted reverses the conventional agency cycle.

```
Build -> Show -> Quote -> Charge -> Deliver
```

Prospects approve real work progressively instead of buying a promise. For Sites, the client sees a high-fidelity mockup before code is written and a working static site before the CMS is added or the quote is accepted.

## Why It Matters

- The mockup creates the emotional pull.
- The working build proves execution and removes surprise.
- The quote follows two approvals, so objections are surfaced against something tangible.
- Payment unlocks handoff, including CMS access and reset capability.

The model is not free speculative work without boundaries. It is a structured conversion system governed by the Four Nods.
