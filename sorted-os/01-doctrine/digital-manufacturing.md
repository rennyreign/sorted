# Digital Manufacturing

Sorted operates as a digital manufacturing company, not a traditional web agency. Work is decomposed into small, deterministic operators with explicit inputs, outputs, quality gates, and handoffs.

## Principles

- Specialise tasks instead of relying on one broad prompt or person.
- Put intelligence in protocols, schemas, and infrastructure rather than individuals.
- Make each operator independently testable and resumable.
- Validate artifacts before downstream work begins.

The Sites line uses the same discipline as Ops: identify a repeatable business problem, install a defined system, and measure the outcome.

## Execution Modes

The default mode is an orchestration agent executing a single client build end to end. At scale, the same skills become stateless CLI operators coordinated by a job queue. The doctrine and artifact contracts remain the same; only the runtime changes.
