# China Phenomenon

The China-phenomenon framework is Sorted's discipline of microscopic specialisation. Complex work is split into the smallest useful deterministic units so output is fast, reliable, and scalable.

## Applied Rules

- An operator has one bounded responsibility and one defined output.
- Operators do not depend on informal conversation; they read and write a shared state record.
- If a human must remain present during a sub-task, that sub-task is not yet an operator.
- As a task becomes more tightly specified, it can move to a less expensive model without sacrificing quality.

Current operator roles include prospect finding, website analysis, mockup deconstruction, asset generation, frontend building, CMS setup, and QA. The aim is system intelligence: a factory that keeps working as knowledge moves out of individual heads and into the operating infrastructure.
