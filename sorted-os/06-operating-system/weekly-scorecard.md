# Weekly Scorecard

The weekly scorecard is the evidence layer for the active acquisition system. Track:

- Mockups created
- Mockups viewed
- Outreach sent
- Positive replies
- Sites sold
- Sites launched
- Revenue

The current CRM dashboard also exposes active pipeline count, response rate, mockup-reveal rate, and conversion rate. These are the established weekly visibility measures for the Sites acquisition path.

Ops work should additionally report capacity returned, manual tasks or checks removed, gaps closed, and value created where those figures are validly measured. Formal definitions and targets belong in `08-metrics` once agreed.
