# Project System

## Sites Project Lifecycle

1. Acquire and qualify the prospect.
2. Obtain Nod 1 on the mockup.
3. Build the static site and pass the Stage 1 quality gate.
4. Obtain Nod 2.
5. Apply SortedUpdates and prepare the delivery layer.
6. Present the quote for Nod 3.
7. Receive payment for Nod 4 and complete handoff.

Projects use artifact checkpoints and branch-based development. Feature work belongs on a `feat/<description>` branch; a deploy preview is reviewed before intentional release to `main`.
