# Sorted Sites Overview

Sorted Sites builds websites for local businesses using the reversed product cycle: the prospect sees the result before being asked to pay.

The purpose of a site is practical: make a business easier to trust, understand, contact, and buy from. A website is also a gateway into wider modernisation work where needed.

## Delivery Boundary

Stage 1 is a static build for client evaluation. Stage 2 starts only after Nod 2 and adds SortedUpdates, client CMS access, tutorial material, and factory-reset capability.

The client owns visible content. Sorted owns layout, composition, typography, design tokens, code, structural changes, and the reset key.
