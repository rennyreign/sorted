# Terminology

| Term | Meaning |
|---|---|
| Vision | The long-term destination for Sorted. |
| GAP | The operating bridge between today and the Vision. |
| Goal | A measurable outcome for a defined period. |
| Action | A strategic quarterly action required to achieve a goal. |
| Project | A discrete work package that fulfils an action. |
| Data dashboard | The evidence layer used to track whether the operating system is moving. |
| Acquisition Engine | The system that finds businesses, creates proof, generates a Nod, and acquires customers. |
| Manufacturing Engine | The system that converts a requirement into a QA-assured deployed artifact. |
| Expansion Engine | The system that identifies adjacent customer needs and deploys relevant Ops products. |
| Improvement Engine | The compounding loop that turns operating volume and data into better operators, lower costs, and greater capacity. |
| Sorted Global | The whole economic machine: Sites, Ops, operator infrastructure, partner distribution, and the relationships between them. |
| Substance | The real capability, product, expertise, systems, evidence, and capacity that makes a promise trustworthy. |
| Signal | The market-facing proof of substance: content, outreach, brand, demonstrations, case studies, and reputation. |
| Conversation | Attention becoming interaction, where credibility becomes personal trust. |
| Deal | An exchange made after enough trust and perceived value have accumulated. |
| Value | The customer receiving the promised outcome and deciding whether trust was justified. |
| Trust Loop | Substance -> Signal -> Conversation -> Deal -> Value, with delivered value strengthening both substance and signal. |
| Law of Substance | The governing law: substance before signal; build real, two-way value, expose it fairly, and let delivery become proof. |
| Rooted Decision Tree | The ten-gate recognition tool used to decide whether an opportunity contains enough reality and substance to commercialise. |
| Signal integrity | Signal that reveals substance rather than compensating for its absence. |
| Two-way value | A sustainable exchange in which buyer value exceeds sacrifice and seller value exceeds delivery cost. |
| Experiential substance | Observable substance shown before purchase so the buyer needs less belief. |
| Propagation | Delivered value becoming buyer-generated evidence, proof, and future signal. |
| Congruence | Claim, action, and customer reality remaining aligned under perfect information. |
