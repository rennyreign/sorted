# Terminology

| Term | Meaning |
|---|---|
| Vision | The long-term destination for Sorted. |
| GAP | The operating bridge between today and the Vision. |
| Goal | A measurable outcome for a defined period. |
| Action | A strategic quarterly action required to achieve a goal. |
| Project | A discrete work package that fulfils an action. |
| Data dashboard | The evidence layer used to track whether the operating system is moving. |
| Acquisition Engine | The system that finds businesses, creates proof, generates a Nod, and acquires customers. |
| Manufacturing Engine | The system that converts a requirement into a QA-assured deployed artifact. |
| Expansion Engine | The system that identifies adjacent customer needs and deploys relevant Ops products. |
| Improvement Engine | The compounding loop that turns operating volume and data into better operators, lower costs, and greater capacity. |
| Sorted Global | The whole economic machine: Sites, Ops, operator infrastructure, partner distribution, and the relationships between them. |
