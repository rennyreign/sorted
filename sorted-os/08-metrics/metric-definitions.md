# Metric Definitions

| Metric | Definition |
|---|---|
| Mockups created | The number of prospect or client mockups produced in the reporting period. |
| Mockups viewed | The number of mockups viewed by prospects in the reporting period. |
| Outreach sent | The number of outbound prospect contacts sent in the reporting period. |
| Positive replies | The number of replies indicating interest or a viable next conversation. |
| Sites sold | The number of Sites engagements sold in the reporting period. |
| Sites launched | The number of client sites launched in the reporting period. |
| Revenue | Revenue recorded in the reporting period. |

Formal calculation rules, sources of truth, targets, and reporting periods remain to be defined.
