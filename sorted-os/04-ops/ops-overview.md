# Sorted Ops Overview

Sorted Ops removes repetitive work, recovers capacity, and improves operational performance for revenue-generating small businesses.

The operating sequence is:

```
Inspect -> Diagnose -> Install -> Integrate -> Improve
```

Start with one costly gap, install one working fix, measure the change, then decide what to improve next. The business owns the operational outcome; Sorted brings systems, integrations, implementation, and measurement.
