# Prospect Finder Operator

The Prospect Finder collects local-business prospects from Google Maps and other sources. Its output is a raw list containing business name, address, phone number, website URL, and Google Maps category.

The finder provides candidates; it does not decide outreach. The Website Analyser produces the commercial assessment, and an operator manually chooses which prospects enter the CRM.

The default acquisition focus is Scenario 2, Tier A: high-value project buyers, unless leadership explicitly selects another prioritisation scenario.
