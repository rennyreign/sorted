The public implementation is [Sorted Sites pricing](../../app/sites/pricing/page.tsx). The governing commercial sequence is:

```text
Build -> Inspect -> Nod -> Fixed Price -> Acquire -> Content Setup -> QA -> Launch -> Proof
```

The principle: price to enable profitable, low-friction circulation while the evidence base is being built. Do not substitute an invented price menu or vague public flexibility for a known artifact, a clear fixed price, and a fair exchange.
