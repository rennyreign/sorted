# Website QA Checklist

## Conversion

- [ ] Primary CTA visible above the fold
- [ ] Contact path obvious
- [ ] Mobile CTA easy to access

## Content

- [ ] No lorem ipsum
- [ ] No placeholder copy
- [ ] Copy sounds human and local
- [ ] Services/products are clear

## Design

- [ ] Layout matches approved direction
- [ ] Mobile layout checked
- [ ] No horizontal scrolling
- [ ] Images cropped correctly
- [ ] Typography hierarchy clean
- [ ] Animations smooth and restrained

## Technical

- [ ] Metadata added
- [ ] Alt text added
- [ ] Footer links added
- [ ] No dead links
- [ ] No obvious console errors
- [ ] Responsive behaviour verified

## Launch QA

- [ ] Desktop, tablet, mobile, and wide desktop reviewed
- [ ] All links and CTAs tested
- [ ] Forms / booking / checkout tested end-to-end where relevant
- [ ] Phone, email, and WhatsApp links tested where relevant
- [ ] Analytics conversion events verified
- [ ] Images compressed, responsive where practical, and not oversized for display size
- [ ] Hero/LCP image is not lazy-loaded
- [ ] Below-fold images lazy-load
- [ ] Image dimensions or stable aspect ratios declared
- [ ] Lighthouse mobile targets reviewed
- [ ] Canonical URL, robots, sitemap, OG metadata, favicon, and 404 verified
- [ ] No staging URL, localhost URL, placeholder href, lorem ipsum, or example contact details
- [ ] HTTPS and canonical host redirects verified
- [ ] Recovery baseline commit/tag recorded
- [ ] Ownership notes completed: domain, CMS, analytics, forms, integrations

## Final

- [ ] Site feels owner-ready
- [ ] Premium treatment consistent if applicable
- [ ] Contact details correct
- [ ] Final pass completed
