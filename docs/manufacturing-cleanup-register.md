# Manufacturing Artifact Lifecycle Register

This register removes obsolete defaults from active execution without deleting useful capabilities or client evidence. It is not permission to delete directories, credentials, caches or historical work.

## Active

- `operators/skills/factory-operators.md`: canonical executable lifecycle contracts.
- `operators/skills/workspace-build.md` and acquisition hub v2 section in `start-build.md`: human-approved workspace handoff.
- Factory intake, asset optimisation/registry, frontend, independent QA/correction, systemisation/design extraction, core QA, internal pages, CMS/CMS QA, analytics, launch and deployment: retain all responsibilities and approval gates.
- CMS templates/workflow and the distinct Sorted Updates maintenance operator: different capabilities, not interchangeable implementations.
- Client input originals, approval references, QA evidence, continuity logs and current/public compatibility routes: preserve provenance and behaviour.

## Dormant Fallback

- `operators/mockup-deconstructor/`: use only for explicitly missing design interpretation; supplied design-IR is not regenerated by default.
- `operators/asset-generator/`: use only for explicitly missing/replacement images with required permission; complete export packs bypass local generation.
- `operators/frontend-builder/implementation/`: older text-context API generation path; not default or a proven scale solution. Keep safety fixes and explicit install/network boundaries.
- Legacy deconstruction/generation artifact schemas in doctrine: retained compatibility, clearly marked as non-default.

## Superseded Guidance

- `.devin/workflows/new-client-site.md`: preapproval main pushes/hosting removed; now local supplied-pack scaffolding.
- `templates/client-site/README.md`: manual destructive copy/push recipe replaced by guarded local intake and feature branch.
- `docs/ad-previewer.md`: sibling portal location marked superseded by shared Sorted Ads.
- Old mandatory user-model-switch and confidence-based vision skips: replaced by actual capability detection and required independent review.
- Broad context loading at every phase: replaced by canonical task contract plus relevant lifecycle references, not indiscriminate removal of quality instructions.
- Template simulated Updates workflow: excluded from manufactured Stage 1 sites; any retained template route must say it is unavailable rather than claim changes were applied.

## Retain Pending Ownership Review

- Tracked `tmp-nexus-*` and `tmp-screenshot.js`: assess extraction into shared tools or experiment archive; no deletion in this pass.
- Ignored site-composer outputs and assemblies: historical prototypes; lack of tracked files does not imply permission to delete local work.
- Sparse mockup-fidelity/owner-identifier directories and local operator environments: may hold credentials/state or active dependencies.
- Empty `sorted-skills/` scaffolding: low priority, not a manufacturing bottleneck.
- `archive/`, mockups, input sources, cached/build output: establish retention and active-process checks before any cleanup.
- Global/repo skill copies: keep scope clear; do not edit user-wide copies from a repository refactor.

## Reference Hygiene

Factory metadata references the maintained common contract rather than nonexistent individual `op-*` documents. Op 5b retains its specific visual-review contract. Legacy skill entry points route into these contracts without starting a second manufacturing path.

Actual deletion/relocation requires a separate explicit file list, owner/reference check and confirmation. No production route, deployment workflow, acquired prospect data or historical client evidence should be removed merely because it is absent from the simplified diagram.
